# Быстрая настройка изолированных сред Вендора C (Desktop GUI в WSL2 и Code CLI в Windows)

> [!NOTE]
> **Исследовательские цели:**
> Данный набор скриптов и руководств разработан исключительно в **исследовательских и образовательных целях**: для изучения архитектуры изоляции процессов Electron/Chromium и CLI, независимой маршрутизации сетевых сокетов (SOCKS5/HTTP), исследования механизмов сессионных шин DBus, Secret Service (GNOME Keyring) и Windows Credential Manager, а также для тестирования надежности изоляции рабочих сред и предотвращения утечек трафика.

Данный набор утилит автоматизирует создание полностью независимых экземпляров **Vendor C Desktop GUI (Linux / WSLg)** и **Vendor C Code CLI (Windows)** с индивидуальной изоляцией состояния, хранилищ авторизации и сетевых сокетов, с бесшовной интеграцией ярлыков на Рабочий стол Windows.

> [!TIP]
> Полное архитектурное и пошаговое руководство с картой скиллов, реестром скриптов и деталями работы GNOME Keyring находится в файле [`howToCreate.md`](howToCreate.md).

---

## 1. Быстрый запуск

### Добавление изолированного профиля Vendor C Desktop GUI (WSL):
```cmd
python C:\MyFiles\vless2socks\new_claude\add_vendor_c_gui_instance.py --id 3 --port 1020 --color purple
```
Создает ярлык на Рабочем столе: `GUI_1020.lnk`.

### Добавление изолированного профиля Vendor C Code CLI (Windows):
```cmd
python C:\MyFiles\vless2socks\new_claude\add_vendor_c_cli_instance.py --id 3 --port 1020 --color purple
```
Создает ярлык на Рабочем столе: `CLI_1020.lnk`.

*(Доступен интерактивный режим с мастером: запустите с флагом `--interactive`).*

## 2. Защита от утечек и Mac UI Оповещения (`verify_and_notify.py`)

Перед каждым запуском вторичных экземпляров (GUI и CLI) выполняется сквозная проверка:
1. **Проверка соответствия IP:** Проверяется фактический выходной IP через сокет `127.0.0.1:<port>`. Он должен совпадать с IP ноды, настроенной в `vless2socks` (`instances.json` / `geo_ip`).
2. **Защита от утечки в 1015 / прямой ISP:** Если трафик выходит с IP базового сокета 1015 или напрямую без прокси, запуск немедленно прерывается.
3. **Mac UI всплывающее окно:**
   - Отображается в нижнем правом углу экрана над панелью задач.
   - Оформлено в тёмной теме macOS Dark Mode с бейджем `GUI vless2socks`.
   - **Успех (Неблокирующий запуск):** Проверка IP выполняется за ~0.3-0.5 сек. Всплывающее окно спавнится в отдельном фоновом процессе на **4.0 секунды**, а лаунчер мгновенно получает код `0`, запуская Vendor C GUI / CLI **моментально без задержек**.
   - **Ошибка:** Показывает обнаруженный IP и ожидаемый IP красным цветом в течение **5.0 секунд**, плавно затухает, код возврата `1` -> **полностью блокирует запуск приложения**.

## 3. Архитектурные действия скрипта

1. **Внутри WSL (Linux):**
   - Создает изолированный домашний каталог `/home/79251/.claude-<id>` с конфигурацией `/home/79251/.claude-<id>/.config/Claude`.
   - Настраивает изолированный сессионный DBus и runtime-каталог `/run/user/1000/claude-<id>` (предотвращает конфликты сокетов).
   - Точечно переопределяет прокси только для этого инстанса (`SOCKS5 127.0.0.1:<port>`, `HTTP 127.0.0.1:<http_port>`), не затрагивая глобальный прокси WSL (`/etc/profile.d/herdr_claude_env.sh`).
   - Устанавливает лаунчер `/usr/local/bin/claude-gui-<id>` с контролем PID, фокусом существующего окна и фоновым демоном очистки процессов при закрытии окна.

2. **На стороне Windows:**
   - Генерирует бесшумный VBS-лаунчер `C:\MyFiles\herdrCenter\run_claude_gui_<id>.vbs` с интеграцией проверки `verify_and_notify.py` (без появления консоли cmd).
   - Создает `.bat` лаунчеры в папке прокси: `C:\MyFiles\Proxy\Vendor_C_Socket_<port>.bat` (и алиас `Claude_Socket_<port>.bat`).
   - Генерирует или подбирает цветную multi-res иконку `C:\MyFiles\Proxy\ico\claude_<color>.ico`.
   - Создает ярлык на Рабочем столе Windows: `C:\Users\79251\Desktop\GUI_<port>.lnk` (для GUI) или `CLI_<port>.lnk` (для CLI).
   - Создает резервную копию ярлыка в каталоге `C:\MyFiles\Proxy\ink\`.
   - Обновляет кэш иконок Windows (`ie4uinit.exe -show`).

## 4. Файловая структура

- `init_wsl_keyring.sh` — скрипт автоматического провижининга и валидации GNOME Keyring в WSL2.
- `verify_and_notify.py` — проверка соответствия IP vless2socks и отрисовка Mac UI тоста (4s/5s fadeout).
- `add_vendor_c_gui_instance.py` (алиас: `add_claude_gui_instance.py`) — мастер настройки GUI инстансов в WSL2/WSLg.
- `add_vendor_c_cli_instance.py` (алиас: `add_claude_cli_instance.py`) — мастер настройки CLI инстансов на Windows.
- `create_desktop_shortcut.ps1` — PowerShell-утилита генерации ярлыков (UTF-8 BOM).
- `template_claude_gui.sh` — шаблон лаунчера WSL.
- `template_run_gui.vbs` — шаблон бесшумного запуска Windows с pre-launch проверкой.
- `vendor_c_accounts.py` / `vendor_c_sync.py` (алиасы: `claude_accounts.py` / `claude_account_sync.py`) — парсинг профилей Vendor C и синхронизация с GUI vless2socks через IPC.

## 5. Интеграция с SystemProxy в vless2socks GUI

В режиме **«Обзор»** (`Overview`) vless2socks автоматически привязывает системные прокси к профилям Вендора C:
1. **Нумерация по умолчанию:**
   - **1 профиль** ──► Порт `1015` (`C:\Users\79251\.claude.json`)
   - **2 профиль** ──► Порт `1016` (`C:\Users\79251\.claude-2\.claude.json`)
   - **N профиль** ──► Порт `1015 + (N - 1)` (`C:\Users\79251\.claude-N\.claude.json`)
2. **Отображение в карточке «Обзор»:**
   - Бейдж 1: `⚙️ System_Proxy ({N} профиль)` (желтый акцент)
   - Бейдж 2: `👤 {email}` (персиковый акцент) или `👤 Не авторизован` (серый)
   - Строка портов: `SOCKS5: 127.0.0.1:{port} | Vendor C [{N}]: {email}`
3. **Автоактуализация:**
   - При каждом запуске CLI консоли скрипт `vendor_c_sync.py` проверяет файл конфигурации, сохраняет кэш и шлет IPC-сигнал `REFRESH` в GUI vless2socks.
   - Бейджи и данные карточки обновляются на лету в основном потоке интерфейса.
